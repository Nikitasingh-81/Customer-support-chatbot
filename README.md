# Customer Support Chatbot Using Deep Learning and NLP

An academic intent-classification chatbot built with TensorFlow/Keras, NLP text vectorization, and Streamlit.

## What the application does

1. Accepts a customer message.
2. Uses a trained neural network to predict its customer-support intent.
3. Checks the prediction confidence against a configured threshold.
4. Returns a predefined response template or a fallback response.

**Limitations:** This prototype does not connect to live order, payment, shipping, refund, or account systems. It cannot actually perform these actions.

## Option A — Train in Google Colab

1. Open `notebooks/Customer_Support_Chatbot_Colab.ipynb` in Google Colab.
2. Run the notebook cells from top to bottom.
3. Upload the three CSV files from `data/` when prompted.
4. Complete training and evaluation.
5. Save/download `customer_support_intent_model.keras` and `customer_support_metadata.json`.
6. Create the `models/` folder in this repository (if needed) and upload both files into it.

## Option B — Train locally

Use Python 3.12. From the repository root:

```bash
python -m venv .venv
```

Activate the environment, then install dependencies:

```bash
pip install -r requirements.txt
```

Train:

```bash
python train_model.py
```

The script reads the three CSVs from `data/`, trains the notebook's neural-network architecture, evaluates on the held-out testing split, and saves:

```text
models/customer_support_intent_model.keras
models/customer_support_metadata.json
```

It also writes actual evaluation files into `outputs/`.

## Run Streamlit locally

After both trained files exist:

```bash
streamlit run app.py
```

## Deploy on Streamlit Community Cloud

1. Push the complete repository to GitHub.
2. In Streamlit Community Cloud, choose **Create app**.
3. Select this repository and the `main` branch.
4. Set **Main file path** to `app.py`.
5. Select Python 3.12 in Advanced settings if the setting is shown.
6. Deploy.

The repository includes `.python-version` set to `3.12`; if the Cloud app has an explicit Python-version setting, ensure it is also set to 3.12. TensorFlow 2.18.0 does not support Python 3.14.

## Model architecture

The training implementation uses the original notebook architecture:

- `TextVectorization` (adapted only on training utterances)
- `Embedding`
- `GlobalAveragePooling1D`
- `Dense(64, ReLU)`
- `Dropout(0.30)`
- `Dense(number_of_intents, Softmax)`

Optimizer: Adam  
Loss: sparse categorical crossentropy  
Training controls: validation monitoring, early stopping, and best-validation-loss checkpointing.

## Data and evaluation

The supplied training, validation, and testing datasets are kept separate. The test dataset is used for final evaluation only. Do not claim model accuracy until the training script/notebook has actually completed and produced the evaluation output.

## Troubleshooting

- **“Trained model files not found”**: Upload both files into `models/` with the exact filenames above.
- **TensorFlow installation fails**: Use Python 3.12, not Python 3.14, with TensorFlow 2.18.0.
- **Metadata/model mismatch**: Generate the model and metadata together from the same training run; do not mix files from different runs.
- **App changes do not appear**: Commit changes to GitHub and reboot the Streamlit app.
